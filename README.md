## ✨ Key Features Built for Gym Owners

### 💳 Dynamic Membership Plans & Pricing Toggle
* **Interactive Billing Switcher:** Members can toggle between **1 Month, 3 Months (5% Off), 6 Months (10% Off), and 12 Months (20% Off + 1 Month Free)** with automatic discount calculations.
* **Student & Promo Highlights:** Dedicated callouts for free day passes and student discounts.

### 📅 Interactive Weekly Class Timetable
* **Multi-Filter Search:** Visitors can filter classes by **Day of the Week**, **Intensity Level** (Low, Medium, High), **Category** (Cardio, Strength, Mind & Body, Dance), and **Beginner-Friendly** status.
* **Dual View Modes:** Switch seamlessly between a clean **Card Grid View** and a compact **Table View**.
* **Spot Tracking & Booking Modal:** Displays available spots per session with an instant pop-up booking form.

### 🧮 Built-In BMI Calculator & Goal Recommender
* Calculates Body Mass Index (BMI) in real time based on weight, height, age, and fitness goal (*Lose Weight, Gain Muscle, Stay Fit, General Health*).
* Automatically recommends the best membership tier and training plan based on the user's result.

### 🥊 Trainer Profiles & 1-on-1 Personal Training
* Filterable trainer directory by specialty (*Boxing, Yoga, Strength, Spin, Zumba*).
* Personal Training session packages with clear time slots and direct WhatsApp booking integration.

### 📝 Smart Join Form & "My Bookings" Tracker
* Live price calculation as users select their membership plan and duration.
* Built-in **My Bookings** drawer allowing visitors to review, filter, and manage their saved class spots, PT sessions, and membership sign-ups.

### 🎨 Modern UX & Local Utility
* **Dark / Light Mode Toggle:** One-click theme switching for comfortable browsing day or night.
* **Live Local Weather & Daily Motivation Widget:** Displays real-time local weather and rotating fitness quotes.
* **100% Mobile-First & Fast:** Styled with Tailwind CSS for instant loading on mobile data connections.

## 🛠️ Easy Customization

All business data—including membership prices, class schedules, trainer profiles, contact details, and opening hours—is stored cleanly in a single JavaScript data file (`js/data.js`). You can update the entire website's pricing and timetable in minutes without touching the HTML layout.

### Quick Setup
1. Clone or download the repository.
2. Replace placeholder images in the `images/` folder with your gym's real photos.
3. Edit `js/data.js` to update your plans, classes, trainers, and WhatsApp contact number.
4. Deploy to any static host (cPanel, Vercel, Netlify, or GitHub Pages).
